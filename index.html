AboutMy ePortfolio

This Computer Science ePortfolio, was developed as part of the CS-499 Computer Science Capstone at Southern New Hampshire University. This portfolio represents the knowledge, technical skills, and experience I have gained throughout my computer science degree program, with a concentration in Software Engineering.

Throughout my coursework, I developed a stronger understanding of software development, application architecture, database management, and security. My experiences also helped me discover an interest in full-stack development, where I can work with both front-end and back-end technologies to build functional applications.

This ePortfolio highlights my growth as a developer through a professional self-assessment, code review, and three enhancements to an existing full-stack application.

Featured Capstone Project: Travlr Getaways

The primary artifact featured in this portfolio is Travlr Getaways, a full-stack travel application originally developed during CS-465 Full Stack Development.

The application uses the MEAN stack, consisting of MongoDB, Express.js, Angular, and Node.js. These technologies work together to manage travel packages, process API requests, and display trip information through a web interface.

For my CS-499 capstone, I selected this application because it provided an opportunity to demonstrate improvements across multiple areas of computer science. Rather than replacing the original application, I implemented focused enhancements that improved security, data processing, and database functionality.
