Travlr Getaways Code Review

This code review examines the original Travlr Getaways application developed during CS-465. The review evaluates the existing application structure, identifies areas for improvement, and outlines the enhancements planned for the CS-499 capstone.

The review focuses on software design and engineering, algorithms and data structures, and database functionality. These areas form the foundation for the three enhancements documented throughout this ePortfolio.

Code Review Walkthrough

Code Review Findings

Before implementing my CS-499 enhancements, I reviewed the original Travlr Getaways application to evaluate its existing functionality, code structure, and areas that could benefit from improvement. This review helped me identify changes that would strengthen security, improve the user experience, and expand database functionality.

Software Design and Engineering

One area identified during the review was the application's access control. Although the original application supported authentication, additional authorization checks were needed to distinguish between regular users and administrators. I also identified opportunities to improve error handling and defensive programming. These findings guided my first enhancement, which focused on JWT authentication, role-based authorization, and protected API operations.

Algorithms and Data Structures

The original trip listing displayed available travel packages but offered limited options for organizing or locating specific trips. I identified an opportunity to improve usability by introducing search and sorting functionality. My second enhancement addresses this limitation by implementing client-side trip searching and price sorting using Angular and TypeScript.

Databases

The original application retrieved trip information from MongoDB without allowing users to filter results by a selected price range. I identified an opportunity to extend the existing API to support database-side filtering. My third enhancement introduced minimum and maximum price parameters and MongoDB comparison operators to retrieve trips within a specified price range.
